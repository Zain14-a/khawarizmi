# 🤖 روبوت محادثة ذكي (Chatbot)

شات بوت بسيط يشتغل من الترمينال، يتذكر سياق المحادثة، ويدعم **مزوّدين مجانيين 100%**:

| المزوّد | التكلفة | الحدود التقريبية المجانية |
|---------|---------|---------------------------|
| **Gemini** (جوجل) | مجاني ✅ | ~10-15 طلب/دقيقة + مئات لألف+ طلب/يوم |
| **Groq** | مجاني ✅ | ~30 طلب/دقيقة + ~1000 طلب/يوم — سرعة رد خرافية |
| OpenAI | مدفوع ❌ | — |

## 📋 المتطلبات

- Python 3.10 أو أحدث
- مفتاح API مجاني من Gemini أو Groq (بدون بطاقة ائتمانية)

## 🚀 خطوات التشغيل

### 1. تنصيب المكتبات

```bash
pip install -r requirements.txt
```

### 2. الحصول على مفتاح مجاني

**الخيار الأول — Gemini (موصى به):**
1. اذهب إلى https://aistudio.google.com/apikey
2. سجّل دخولك بحساب Google
3. اضغط **Create API key** وانسخ المفتاح

**الخيار الثاني — Groq:**
1. اذهب إلى https://console.groq.com/keys
2. سجّل دخولك وأنشئ مفتاح جديد

### 3. إعداد ملف `.env`

- الصق المفتاح مكان `ضع-مفتاحك-هنا`
- إذا استخدمت Groq، غيّر `PROVIDER=groq`

### 4أ. تشغيل الموقع 🌐 (موصى به)

```bash
pip install waitress
python app.py
```

ثم افتح المتصفح على: **http://127.0.0.1:5000**

> 💡 `app.py` يستخدم خادم **waitress** الإنتاجي تلقائياً (يدعم عدة مستخدمين بالتوازي) — إن لم يكن مثبّتاً يعود لخادم Flask التطويري كاحتياط.

أول مرة، اضغط **"أنشئ حساب جديد"** وسجّل بإيميل وكلمة مرور (كلمات المرور مخزّنة مشفّرة).
بعدها تقدر تسجّل دخولك بأي وقت، تبدّل الموديل من الشريط العلوي، وكل محادثاتك محفوظة.

### 4ب. أو تشغيل البوت من الترمينال 💻

```bash
python chatbot.py
```

اكتب أي شيء واضغط Enter. لإنهاء المحادثة اكتب `خروج` أو `exit`.

## ⚙️ التخصيص

- **شخصية البوت:** عدّل `SYSTEM_PROMPT` في `chatbot.py`
- **النموذج:** حدّد `MODEL` في `.env` (اتركه فاضياً للنموذج الافتراضي)
- **تبديل المزوّد:** غيّر `PROVIDER` في `.env` بين `gemini` / `groq` / `openai`

## 🎬 توليد الفيديو (اختياري — يحتاج رصيداً)

توليد الفيديو مبني بالكامل في الموقع، لكنه **معطّل افتراضياً** لأن كل نماذج الفيديو
في Pollinations مدفوعة (لا يوجد بديل مجاني، خلاف الصور).

**كيف يتفعّل؟**

1. أنشئ حساباً على https://pollinations.ai واحصل على رصيد Pollen
   (يُشترى من لوحة التحكم، `$1 ≈ 1 Pollen`، والحسابات الجديدة تأخذ رصيداً ترحيبياً مجانياً).
2. أنشئ **مفتاحاً سرياً (Secret Key)** يبدأ بـ `sk_` من لوحة الحساب.
3. ضعه في `.env`:

   ```env
   POLLINATIONS_KEY=sk_xxxxxxxxxxxxxxxx
   ```

4. أعد تشغيل السيرفر — تظهر تلقائياً:
   - زر **«توليد فيديو»** في صندوق الكتابة
   - بطاقة **«ولّد فيديو قصير»** في شاشة الترحيب
   - نماذج الفيديو مسبوقة بـ 🎬 داخل قائمة النماذج العلوية
   - أوامر سريعة: `/video وصف المشهد` أو `فيديو: وصف المشهد`

**التكلفة التقريبية:** الفيديو يُحسب **بالثانية** من رصيد Pollen — المقطع 5 ثوانٍ
يتراوح بين ~$0.40 و ~$0.65 حسب النموذج (Hailuo 02 ≈ $0.08/ثانية، Veo 3.1 Fast ≈
$0.10/ثانية، Seedance 2.0 و Wan 2.2 ≈ $0.13/ثانية).

**بدون المفتاح:** كل واجهات الفيديو تختفي تماماً من الموقع (لا زر، لا مودال، لا نماذج)،
والبوابة `/api/generate-video` ترجع 503 مع رسالة واضحة — فلا يحصل أي استدعاء مدفوع بالخطأ.

## 🌍 نشر الموقع للعامة (Render — مجاني، يُنشر من GitHub)

الموقع جاهز للنشر العام — الخوارزمي يخدم كل العرب بدون تكلفة.

### الخطوات

1. **ارفع الكود إلى GitHub** (مستودع عام):
   ```bash
   git init
   git add .
   git commit -m "إطلاق الخوارزمي"
   gh repo create khawarizmi --public --source . --push
   ```
   > `.gitignore` يمنع رفع `.env` (المفاتيح) و `users.json` (الحسابات) تلقائياً.

2. **أنشئ حساباً على Render** (مجاني، بدون بطاقة ائتمانية): https://render.com → **Sign up** (يمكن عبر GitHub مباشرة)

3. **أنشئ خدمة ويب جديدة**: Dashboard → **New +** → **Web Service** → اختر مستودع `khawarizmi`:
   - **Name:** `khawarizmi` → عنوانك: **`khawarizmi.onrender.com`**
   - **Runtime:** Python 3
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn wsgi:application --bind 0.0.0.0:$PORT --worker-class gthread --threads 16 --timeout 180` (16 خيطاً = يخدم عدة مستخدمين بالوقت نفسه لتجنب الطابور)
   - **Plan:** Free
   - **Environment** (Environment Variables):
     - `SECRET_KEY` → أنشئ مفتاحاً عشوائياً طويلاً
     - `GEMINI_API_KEY` → المفتاح من `.env` المحلي
     - `GROQ_API_KEY` → المفتاح من `.env` المحلي
     - `OPENROUTER_API_KEY` → المفتاح من `.env` المحلي
     - `POLLINATIONS_KEY` → مفتاح Pollinations السري (`sk_`) — **مطلوب فقط إذا بدك توليد الفيديو** (الصور ما تحتاجه)
      - `APINEX_API_KEY` -> مفتاح APInex (1M token مجاني) من apinex.bond
      - `DAILY_BUDGET` -> ميزانية النموذج المجاني/يوم (افتراضي 2000)
      - `USER_DAILY_TOKEN_LIMIT` -> حد التوكنز لكل مستخدم/يوم (افتراضي 20,000)
      - `USER_DAILY_LIMIT` -> حد الطلبات لكل مستخدم/يوم (افتراضي 15)
      - `USER_HOURLY_LIMIT` -> حد الطلبات لكل مستخدم/ساعة (افتراضي 5)
   - اضغط **Create Web Service** → يبني وينشر تلقائياً 🚀

5. **تضخيم الحصص المجانية بمفاتيح متعددة** (اختياري — يضاعف السقف اليومي):
   - الحصص المجانية يومية (مثل: OpenRouter ~50 طلب/يوم، Gemini حصة رموز يومية، Groq أسبوعية)
   - الموقع يدور بين عدة مفاتيح تلقائياً عند وصول أول مفتاح لحده:
     - في لوحة Render أضف `GEMINI_API_KEY_2` و `GEMINI_API_KEY_3` ... (إلى _9)
     - أو ضع عدة مفاتيح في نفس المتغير مفصولة بفواصل: `GEMINI_API_KEY` = `مفتاح1,مفتاح2`
   - نفس الشيء ينطبق على `GROQ_API_KEY` و `OPENROUTER_API_KEY`
   - ⚠️ استخدم مفاتيح من حساباتك الشخصية الفعلية فقط — إنشاء عشرات الحسابات لتكديس الحصص يخالف شروط المزوّدين وقد ينحظر الجميع

4. **أبقِ الموقع مستيقظاً** (أول زائر لا ينتظر):
   - من إعدادات المستودع: **Settings → Secrets and variables → Actions → Variables**
   - أضف: `RENDER_URL` = `https://khawarizmi.onrender.com`
   - (ملف `.github/workflows/keepalive.yml` يرسل طلباً كل 12 دقيقة تلقائياً)
